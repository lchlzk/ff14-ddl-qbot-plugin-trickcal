TRICKCAL BOARD · API V1

让你的蜡笔板
接入更多应用。

第三方程序可以读取用户的角色目录与蜡笔板进度。当前版本仅提供只读接口；个人数据由用户自己的令牌授权。

HTTPSJSONBearer 令牌只读
01

快速接入

  1. 用户登录蜡笔板网页；如尚无账号，先按网页提示在 QQ 群完成绑定。
  2. 在右侧「第三方 API」中点击「管理 API 令牌」，填写用途并生成令牌。令牌只显示一次。
  3. 由你的服务器发送以下请求。不要把令牌放在浏览器脚本、公开仓库、网址参数或群消息里。
请求示例 · cURL
curl --request GET \
  --header 'Authorization: Bearer <你的令牌>' \
  'https://qbot-l.yizhixiaogame.com/api/v1/tr-board/board'

基础地址：https://qbot-l.yizhixiaogame.com。请求与响应均使用 UTF-8；成功响应为 {"ok":true,"data":...}。

02

鉴权与限制

发送方式

Authorization: Bearer <令牌> 请求头；不支持 Cookie 或查询参数传令牌。

有效期

生成后 90 天。每个蜡笔板账号最多同时保留 5 个有效令牌，可在网页随时撤销。

速率

每个令牌最多 60 次／分钟；超过后返回 429 与 Retry-After: 60。

权限

仅能读取令牌所属账号的蜡笔板，以及公开角色目录；不能添加角色或修改节点。

03

角色与节点目录

GET/api/v1/tr-board/catalog

返回公开角色目录和各角色三层的百分比节点、金币及金蜡笔成本。即使只读取公开目录，也仍需有效令牌。响应不含用户的拥有或加点状态。

{
  "ok": true,
  "data": {
    "version": 1,
    "catalog": {
      "fetched": 1780000000,
      "stale": false,
      "sources": ["Soshage", "Crayon-note"]
    },
    "units": [
      {
        "id": 10016,
        "name": "艾尔芬",
        "alias": "Erpin",
        "search_names": ["艾尔芬", "艾爾芬", "Erpin"],
        "personality": 0,
        "portrait": "/tr-board/assets/portraits/10016.webp",
        "layers": [
          {
            "layer": 1,
            "label": "第一层",
            "nodes": [
              {"id": 1, "group": "攻击", "label": "攻击", "gold": 100, "gold_crayons": 1}
            ]
          }
        ]
      }
    ]
  }
}

上面的 ID、数值与目录时间只是格式示例，不代表实时数据；请以接口返回为准。

04

个人蜡笔板

GET/api/v1/tr-board/board

返回令牌所属账号的角色拥有状态、已点及计划节点、分层统计和资源合计。绑定了多个机器人时，读取的是同一份共享蜡笔板。

{
  "ok": true,
  "data": {
    "version": 1,
    "catalog": {"fetched": 1780000000, "stale": false, "sources": ["Soshage"]},
    "summary": {
      "owned": 1, "catalog_units": 76, "progressed": 1,
      "selected": 1, "total": 2, "planned": 0,
      "gold": 100, "gold_crayons": 1,
      "planned_gold": 0, "planned_gold_crayons": 0,
      "updated": 1780000000, "stats": []
    },
    "layers": [
      {"layer": 1, "label": "第一层", "groups": [
        {"group": "攻击", "label": "攻击", "selected": 1, "total": 1}
      ]}
    ],
    "units": [
      {
        "id": 10016, "name": "艾尔芬", "alias": "Erpin",
        "search_names": ["艾尔芬", "Erpin"],
        "personality": 0,

05

字段说明

字段含义
data.version响应结构版本，当前为 1。接入方应先检查版本。
catalog.fetched / stale / sources目录抓取时间（Unix 秒）、是否使用旧缓存、目录来源。
units[].id / name / alias角色数字 ID、简体显示名、英文别名。请用 ID 关联角色，不要依赖显示名。
units[].search_names / personality / portrait搜索别名、性格编号、站内立绘相对路径。立绘可用基础地址补全。
units[].owned / selected / total是否拥有、已点百分比节点数、该角色可用百分比节点总数；仅 board 提供。
units[].layers[].nodes[]每层节点的 id、group、label、gold、gold_crayons；board 另有布尔值 selected 和 planned。
summary个人汇总：拥有角色 owned、有进度角色 progressed、已点 selected／总节点 total／计划 planned、已用与计划金币及金蜡笔、更新时间 updated、累计加成描述 stats。
layers[].groups[]按层与属性分组的已点数 selected 和可点总数 total；仅统计已拥有角色的百分比节点。

节点分组包括攻击、防御、生命、暴击、暴抗；label 是界面展示名称。普通固定数值节点不在当前 API 目录内。

06

错误与安全

HTTP 状态处理方式
200成功；JSON 为 {"ok":true,"data":...}。
401缺少、无效、过期或已撤销令牌。请用户在网页重新授权；不要无限重试。
429超过每令牌每分钟 60 次的限制；按 Retry-After 等待后重试。
405请求方法不受支持；这两个公开接口只接受 GET。
接入建议

只在可信后端保存令牌，使用 HTTPS，不记录完整 Authorization 请求头。撤销后令牌立即失效。当前未开放浏览器跨站调用（CORS），也未开放第三方写入接口。
